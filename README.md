# 🌐 Streamlit Web App Collection

Repositori ini berisi kumpulan skrip Python interaktif berbasis [Streamlit](https://streamlit.io/), dirancang untuk berbagai kebutuhan seperti kalkulator, kuis, permainan, dan penerjemah buku.

---

## 📂 Daftar Skrip Aplikasi

* `book.py` — Antarmuka dasar untuk membaca file buku
* `book-trans.py` — Terjemahan buku berbasis teks
* `completed-book.py` — Versi akhir dengan fungsi lengkap
* `completed-book_v1.1.py` — Versi revisi dengan peningkatan fitur
* `complex-calc.py` — Kalkulator ilmiah dengan logika lanjutan
* `kalkulator.py` — Kalkulator sederhana
* `simplekalkulator.py` — Alternatif kalkulator ringan
* `quiz.py` — Aplikasi kuis interaktif
* `tictac.py` — Permainan Tic Tac Toe berbasis web
* `data.py` — Dataset dummy untuk uji coba

---

## 🚀 Cara Menjalankan Aplikasi

1. **Pastikan sudah menginstal dependensi**

```bash
pip install -r requirements.txt
```

2. **Jalankan aplikasi Streamlit**

Contoh menjalankan `book-trans.py`:

```bash
streamlit run book-trans.py
```

---

## 🧩 Dependensi

Tercantum di file `requirements.txt`, antara lain:

* streamlit
* pandas
* numpy
* googletrans
* dll sesuai modul yang digunakan masing-masing skrip
